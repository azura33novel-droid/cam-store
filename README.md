# CAM Store — projeto inicial

Este repositório contém a primeira estrutura visual da CAM Store em Next.js.

## Requisitos
- Node.js 20 ou superior
- Conta gratuita no GitHub
- Conta na Vercel para hospedagem
- Projeto Supabase para banco, autenticação e armazenamento

## Executar localmente
```bash
npm install
npm run dev
```
Abra http://localhost:3000.

## Próximas etapas
1. Criar projeto no Supabase e configurar variáveis `.env.local` a partir de `.env.example`.
2. Implementar autenticação e permissões de administrador/vendedor.
3. Criar tabelas de vendedores, produtos, imagens, pedidos, avaliações e denúncias.
4. Implementar uploads e moderação.
5. Conectar o repositório à Vercel e publicar.

**Importante:** esta é apenas a base inicial da interface. Cadastro, login, banco de dados, WhatsApp, anúncios reais e painel administrativo ainda não estão implementados.
